# День 3 — Коллекции и алгоритмы обработки данных

## Что выполнено

- Создан список из 15 студентов.
- Для каждого студента указаны имя, возраст, группа и оценки.
- Реализован расчёт среднего балла.
- Реализован вывод топ-5 студентов.
- Реализована фильтрация студентов по группе.
- Реализована сортировка по возрасту.
- Реализована сортировка по среднему баллу.
- Найдены повторяющиеся имена.
- Сформировано множество уникальных групп.
- Реализован текстовый отчёт.

## Использованные возможности Python

- `list`
- `dict`
- `set`
- `sorted`
- `lambda`
- list comprehension
- `sum`
- `Counter`
