# День 2 — Условия, циклы и функции

## Что выполнено

- Реализован CLI-калькулятор.
- Добавлены операции сложения, вычитания, умножения и деления.
- Добавлена обработка некорректного ввода и деления на ноль.
- Реализована функция `is_prime(n)` для проверки простых чисел.
- Выведены простые числа от 1 до 200.
- Реализована функция `validate_age(value)` для проверки возраста от 0 до 120.

## Запуск

Калькулятор:

```bash
python week01/day02/calculator.py
```

Проверка простых чисел:

```bash
python week01/day02/prime.py
```

Проверка возраста:

```bash
python week01/day02/age.py
```

## Примеры

Калькулятор:

```text
Введите операцию (+, -, *, /) или exit для выхода: +
Введите первое число: 10
Введите второе число: 5
Результат: 15.0
```

Проверка возраста:

```text
Введите возраст: 23
Возраст введён корректно
```
