# День 4 — Файлы, pathlib, JSON и CSV

## Что выполнено

- Данные студентов сохранены в JSON.
- Данные студентов сохранены в CSV.
- Реализовано чтение данных из JSON и CSV.
- Выполнено сравнение количества записей.
- Реализован импорт студентов из CSV.
- Некорректные строки при импорте пропускаются.
- Для работы с путями используется `pathlib.Path`.
- Для файлов используется кодировка UTF-8.
- Сформирован текстовый отчёт `reports/report.txt`.
- Добавлена обработка отсутствующих файлов.

## Использованные возможности Python

- `with` и `open` 
- `pathlib.Path`
- `json.load` и `json.dump`
- `csv.DictReader` и `csv.DictWriter`
- `try/except`

## Запуск

```bash
python week01/day04/files.py
```

## Результат

После запуска создаются файлы:

- `students.json`
- `students.csv`
- `reports/report.txt`
