# Учебная практика — Python

Репозиторий для выполнения заданий учебной практики по Python, Django, PostgreSQL и Docker.

## Структура проекта

- `week01/` — задания первой недели.
- `week01/day01/` — задания первого учебного дня.

## Запуск

Создание виртуального окружения:

```bash
python -m venv .venv
```

Запуск задания первого дня:

```bash
python week01/day01/main.py
```
